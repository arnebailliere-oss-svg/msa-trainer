# UI_FLOWS: Screens und Navigation

## 1. Start
- App lädt Dashboard
- Profil wählen oder Profil anlegen

## 2. Dashboard (Schüler)
Elemente:
- Profil Dropdown
- Buttons: Mathe, Deutsch, Englisch
- Start Quick Training
- Karte: Top-3 Fokus heute (Topics)
- Ampelübersicht pro Fach (Liste oder Accordion)

Aktionen:
- Klick auf Fach startet Quick Training in diesem Fach
- Klick auf Topic startet Topic Training

## 3. Session Screen
Layout:
- Header: Fach, Topic Name, Session Fortschritt
- Body: Question Renderer
- Side Panel: Calculator (nur Mathe, optional)
- Footer: Antwortabgabe

Nach Abgabe:
- Feedback Panel: korrekt/falsch + explanation
- Next Button

## 4. Result Screen
- Trefferquote, Zeit, Anzahl Aufgaben
- Heute gestärkt (Top 2 Topics)
- Schwächen (Top 2 Topics)
- Empfehlung: nächste Session (z. B. Fehlerliste)

## 5. Elternbereich
- PIN optional
- Übersicht pro Kind:
  - Zeit pro Tag (einfach)
  - Ampel Themen
  - Top-3 Schwächen
- Settings:
  - Tagesziel Minuten oder Aufgaben
  - Prüfungsmodus: MSA Block aktivieren
